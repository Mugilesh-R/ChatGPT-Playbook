# ChatGPT-Playbook

 The Better Prompt Formula

The core framework behind every prompt in this playbook:

R — Role Who should ChatGPT be?
T — Task What exactly should it do?
C — Context What background does it need?
A — Audience Who is the output for?
R — Requirements Tone, format, length, constraints
E — Examples Show what good looks like
R — Review Check and improve the output
